# Tamil Nadu Assembly Elections 2026 — Analytics Pipeline

An end-to-end election analytics project: raw constituency-level results are
cleaned and enriched with pandas, then turned into three outputs from a single
data model — static charts, an auto-generated branded PowerPoint deck, and an
interactive Power BI dashboard.

## Data note

The result CSVs in `data/` are a **case-study / simulated dataset** modeling a
hypothetical 2026 Tamil Nadu Assembly election (234 constituencies, matching
the real Assembly's seat count, with real Tamil Nadu party names). They are
**not verified official Election Commission of India results** — treat all
figures below as analysis of this dataset, not as real-world electoral fact.

## What's in here

| File | Purpose |
|---|---|
| `election.py` | Original exploratory analysis — seat/region breakdown, flip matrix, margin-of-victory histogram |
| `build_dashboard.py` | Main pipeline: enriches the raw data, exports a 7-table Power BI data model, generates 6 charts, and builds a 10-slide branded PowerPoint deck |
| `upgrade_powerbi_report.py` | Programmatically generates/redesigns the Power BI report definition (PBIR format) — pages, KPI cards, slicers, tables — without touching Power BI Desktop |
| `TN_Election_2026_PowerBI_Theme.json` | Shared Navy & Gold brand theme (colors, fonts) used across the PPT and dashboard |
| `tamilnadu.pbix` | The Power BI dashboard |
| `data/` | Raw result CSVs + `data/outputs/` (generated charts, PPT, and the Power BI data model exports) |

## Tech stack

- **Python**: pandas (data enrichment), matplotlib/seaborn (charts), python-pptx (deck generation)
- **Power BI**: report authoring at the PBIR (schema/JSON) level — pages, slicers, cards, and tables generated by script rather than built by hand in Desktop

## Running it

```bash
pip install pandas numpy matplotlib seaborn python-pptx
python build_dashboard.py          # regenerates charts, PPT, and Power BI data model exports
python upgrade_powerbi_report.py   # regenerates the Power BI report pages/visuals
```

Both scripts resolve paths relative to their own location, so the project
runs from any clone without editing paths.

## Headline findings (from this dataset)

- **163 of 234 constituencies (70%) changed hands** between 2021 and 2026 — a sweeping anti-incumbency swing.
- **TVK emerged as the largest party with 108 seats**, having not existed as a factor in 2021 — the single biggest realignment in the dataset, with its largest inflow coming from DMK (65 seats).
- **The average winning margin nearly halved**: winner vote share fell from 48.8% (2021) to 39.0% (2026).
- **Elections became far more fragmented**: winners exceeding 50% vote share dropped from 84 to 14, while winners below 35% jumped from 2 to 61.
- No single party swept all 6 regions — dominance stayed geographically concentrated even as the overall seat count shifted.
